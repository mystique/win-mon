# Win Mon

Win Mon 是一款 Windows 11 网速监控工具。它在任务栏上显示实时上传和下载速率，也可以通过桌面悬浮窗查看网络活动。

程序没有主窗口。所有设置都在右键菜单中，无需管理员权限。

## 下载与启动

运行环境：**Windows 11 x64**。

1. 打开 [Releases 下载页](https://github.com/mystique/win-mon/releases)。
2. 下载所选版本的 `WinMon-<version>-windows-x64.zip` 压缩包。
3. 将压缩包完整解压到一个文件夹。
4. 双击文件夹中的 `WinMon.exe`。

首次启动后，网速显示在主任务栏的通知区域旁。通知区域中同时显示 Win Mon 图标。右键单击该图标，即可打开设置菜单。

## 查看网速

- 上行数值表示上传速率，箭头为 `↑`，颜色为绿色。
- 下行数值表示下载速率，箭头为 `↓`，颜色为蓝色。
- 数值每秒更新一次，单位自动切换为 `K/s`、`M/s` 或 `G/s`。

默认监控选项为 `All`，汇总当前已连接的硬件网络。若只想查看一个网络，在 `Monitored Network` 中选择对应名称。

虚拟网络和隧道网络不计入 `All`，但可以单独选择。每次重新启动 Win Mon，监控选项都会恢复为 `All`。

## 设置任务栏显示

右键单击 Win Mon 图标，使用以下菜单项：

| 菜单项 | 用途 |
| --- | --- |
| `Show Taskbar Text` | 显示或隐藏任务栏上的网速，默认显示。 |
| `Taskbar Display Position` → `Left` | 在主任务栏左端显示网速。 |
| `Taskbar Display Position` → `Right` | 在通知区域旁显示网速，默认使用此位置。 |
| `Enable Taskbar Context Menu` | 开启后，可以右键单击任务栏上的网速打开菜单。默认关闭。 |
| `Show Tray Icon` | 显示或隐藏通知区域中的 Win Mon 图标，默认显示。 |

任务栏网速仅支持**主显示器底部的任务栏**。副屏任务栏不显示网速。左端空间不足或有其他控件占用时，网速会暂时隐藏。

## 使用悬浮窗

1. 右键单击 Win Mon 图标。
2. 勾选 `Show Floating Display`。

首次开启时，悬浮窗显示在主显示器右上角。它保持置顶，可以拖到其他位置或其他显示器。程序会保存悬浮窗的位置。

| 深色背景 | 浅色背景 |
| --- | --- |
| ![深色背景下的悬浮窗](docs/images/floating-dark.png) | ![浅色背景下的悬浮窗](docs/images/floating-light.png) |

截图中的流量为演示数据。绿色表示上传，蓝色表示下载。圆环和水位反映网络活动，曲线显示近期变化，右侧显示实时数值。

右键单击悬浮窗，可以打开同一设置菜单：

| 菜单项 | 用途 |
| --- | --- |
| `Show Floating Display` | 显示或隐藏悬浮窗，默认隐藏。 |
| `Show Floating Text` | 显示或隐藏悬浮窗中的速率数值。 |
| `Show Floating Charts` | 显示或隐藏悬浮窗中的曲线图。 |
| `Floating Display Opacity` | 调整悬浮窗的不透明度，范围为 10%～100%。100% 为完全不透明。 |

开启悬浮窗后，速率数值和曲线图默认显示。同时隐藏这两项时，悬浮窗只保留圆形。

双击悬浮窗的圆形区域，可以逐步显示或隐藏曲线图和速率数值。双击圆形以外的区域不会切换显示。

## 自动启动与退出

- 勾选 `Start at Sign-in`，登录 Windows 后自动启动 Win Mon。
- 选择 `Exit`，退出 Win Mon。

显示设置和自动启动设置会保留到下次启动。监控网络的选择不保留。

## 常见问题

### 启动后没有主窗口

这是正常情况。Win Mon 通过任务栏、通知区域图标和悬浮窗显示信息。请右键单击通知区域中的 Win Mon 图标打开菜单。

### 任务栏上没有网速

1. 确认 `Show Taskbar Text` 处于勾选状态。
2. 确认主显示器的任务栏位于底部。
3. 若使用 `Left`，尝试切换为 `Right`。

任务栏位置不受支持或显示空间不足时，可以开启 `Show Floating Display` 查看网速。

### 网速一直为零

1. 确认所选网络已连接。
2. 打开网页或下载文件，产生网络活动。
3. 在 `Monitored Network` 中选择 `All` 或正在使用的网络。

所选网络断开时，速率显示为零。所选网络从系统中消失时，程序会恢复为 `All`。

### 某个显示开关无法关闭

程序会保留至少一个可用的右键菜单入口。若关闭某项会导致无法打开菜单，该项会保持勾选并显示为灰色。请先开启另一个菜单入口。
