# Win Mon

Win Mon 是一款面向 Windows 11 的轻量级网速监控工具。它可在主任务栏左端或通知区域旁显示实时上传和下载速率，也可启用独立的桌面悬浮窗。程序不提供主窗口，日常操作通过右键菜单完成。

当前版本：**1.2.0**（Windows 文件版本：`1.2.0.0`）。本版新增任务栏速率文字的左侧/右侧位置选择并保存配置，固定单位和箭头位置，按字体与 DPI 自动预留数字空间。

## 功能

- 在主任务栏上以两行文字显示上传、下载速率，每秒更新一次
- 支持汇总活动硬件网络接口的速率，或监控指定网络接口
- 可启用置顶、可拖动的悬浮窗，通过圆环、渐变波形和水位动画展示网络活动
- 自动使用 `K/s`、`M/s`、`G/s` 单位显示速率
- 支持选择任务栏速率文字的字体和样式，以及左侧/右侧显示位置
- 支持设置登录 Windows 后自动启动
- 可选择是否通过右键单击速率文字打开菜单
- 自动适配 DPI、任务栏主题颜色以及 Explorer 重启
- 以普通用户权限运行，不需要管理员权限

## 系统要求

### 运行

- Windows 11 x64
- 使用任务栏速率文字时，需要位于主显示器底部的任务栏

任务栏速率文字仅显示在主显示器的底部任务栏上，不显示在副屏任务栏中。主任务栏不可用或不位于底部时，任务栏速率文字会隐藏；托盘菜单和已启用的悬浮窗仍可使用。悬浮窗可拖动到其他显示器。

### 构建

- Visual Studio 2022，并安装“使用 C++ 的桌面开发”和 MFC 组件
- CMake 3.25 或更高版本
- Windows 11 SDK

## 构建与测试

在已配置 Visual Studio 编译环境的终端中运行：

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

构建完成后，程序位于：

```text
build/Release/WinMon.exe
```

## 发布

版本号以 `src/WinMon/res/WinMon.rc` 为准。Windows 文件版本为四段（当前 `1.1.0.0`）；末段为 `0` 时，GitHub Release 使用前三段（当前 `v1.1.0`），否则使用完整四段。

推送对应标签，或在 Actions 中手动运行 **Release**，会构建 Release x64、运行测试，并把 `WinMon-<version>-windows-x64.zip` 发布到该版本的 Release。压缩包内是 `WinMon.exe`，以及此构建链接的 Visual C++ 与 MFC 运行库。标签与资源版本不一致，或该标签已指向其他提交时，工作流会失败。同一版本的重新发布必须来自该标签已指向的提交；要发布新版本，先修改资源文件中的版本号。

## 使用方法

1. 启动 `WinMon.exe`。
2. 通过通知区域中的 Win Mon 图标打开右键菜单。
3. 在 **Network to Monitor** 中选择 **All** 或指定网络接口。
4. 在 **Speed Text Position** 中选择 **Left** 或 **Right**（默认右侧）；根据需要启用 **Launch at Login**、**Right-Click Speed Text**、**Show Floating Display**、**Show Floating Speed Text**，或通过 **Set Font...** 调整任务栏字体。
5. 选择 **Exit** 退出程序。

除网络接口选择外，登录启动、速率文字右键菜单开关及显示位置、悬浮窗及其速率文字开关、位置和任务栏字体设置会保存到当前用户的注册表中。每次启动时，网络接口选择会恢复为 **All**。**All** 汇总处于连接状态的硬件接口；虚拟和隧道接口可单独选择，但不参与汇总。所选接口断开时显示零速率，接口从系统中消失时恢复为 **All**。

### 任务栏速率位置

**Left** 在主任务栏左端显示，箭头在数字前；**Right** 在通知区域旁显示，箭头在单位后。数字以单位位置为锚点右对齐，单位和箭头位置固定，字体或 DPI 改变时自动重新测量。预留空间包含四位整数加一位小数；极端超宽数字以省略号显示，单位和箭头保持完整。

左端存在 Widgets、开始按钮或其他控件，或无法确认区域空闲时，速率文字暂时隐藏并每秒重试，保留所选位置；空间不足以容纳完整两行布局时也会暂时隐藏。不会挤压系统任务栏控件，托盘和悬浮窗仍可使用。

### 悬浮窗

通过 **Show Floating Display** 开启，默认关闭。首次开启时位于主显示器工作区右上角；拖动后保存位置，原位置不可用时自动回到主显示器。

- 深色胶囊左侧为绿／蓝上下半环，从各自左右端同时向中点填充；内部水波按网络相对活动改变速度和水位。
- 上传／下载连续曲线分区排列，带淡网格与渐变，严格限制在各自区域内。圆环外径与图表宽度保持 5:8，显示最近 32 次采样。
- 读数采用内置 Punctum 点阵，每行九个固定字符位，小数点为 3×7（21 盏灯），其他字符为 5×7（35 盏灯）。数值上限为 999.9，超出时按当前单位饱和显示；任务栏格式化不受影响。
- **Show Floating Speed Text** 默认开启，关闭时两行读数与暗灯一起淡出，胶囊平滑收窄；打开时展开并淡入。圆环与图表尺寸保持不变，快速切换可以反向过渡，设置跨重启保存。
- 右键打开同一菜单，拖动不激活窗口，阴影点击穿透。禁用 Windows 动画时立即切换。
- **Set Font...** 仅调整任务栏文字，悬浮窗始终采用固定 LED 字形，无需安装字体；发行包附带 Punctum 的 SIL OFL 许可。

## 实现概览

项目使用 C++20、Win32 和 MFC 构建：

- `WinMonCore`：负责网络速率计算、格式化、网络接口选择和菜单模型，不依赖 MFC 或窗口句柄。
- `WinMon`：作为轻量级 Windows 外壳，负责托盘图标、任务栏速率文字、悬浮窗、菜单、定时采样、设置和 Explorer 恢复。
- `RateStrip` 只管理任务栏文字，`FloatingRateDisplay` 独立管理悬浮窗、阴影、拖动和动画；任务栏字体设置保留实时应用、保存和失败回滚，悬浮窗与字体配置解耦。
- `NetworkObservationReader` 集中读取网卡数据和缓存连接分类，定时采样与菜单共用同一实例；网卡列表变化时立即刷新分类，正常缓存 30 秒，查询失败后 2 秒重试。
- 速率文字以子窗口方式嵌入主任务栏，按所选位置在左端或通知区域旁布局；左端通过原生窗口与 XAML 控件边界检查可用空间，无法确认空闲时隐藏并重试。程序不会缩放或永久修改任务栏中的其他窗口。
- 网络计数器每秒读取一次；经典“网络连接”分类复用缓存，网卡 GUID 集合变化时刷新，正常每 30 秒校准，查询失败后每 2 秒重试。
- `FloatingRateRenderer` 使用 Direct2D 软件渲染和分层窗口实现透明显示。水波及窗口宽度共用约 30 FPS 动画定时器，与每秒采样独立；空闲且水位退尽、宽度过渡结束时停止动画定时器，关闭悬浮窗时销毁窗口并释放渲染目标。
- 悬浮窗复用圆弧、趋势路径、渐变画刷和 DC/DIB 缓冲；采样历史或 DPI 变化时更新相应资源。阴影复用，仅在目标重建或提交到新的阴影窗口时重新上传；合成预览像素按需生成。
- CTest 覆盖核心逻辑、任务栏固定栏位与字体/DPI 绘制、位置配置和占用恢复、渲染与缓存失效的一致性，以及原生悬浮窗的移动、重建和 GDI 资源释放。

## 已知限制

- 仅支持 Windows 11 x64。
- 仅在主显示器底部任务栏显示速率文字。
- 不支持 Windows 10；任务栏嵌入不支持副屏或垂直/顶部布局，悬浮窗不受这些任务栏布局限制。
- 网卡 GUID 集合不变时，经典“网络连接”分类的变化最多可能延迟约 30 秒反映；速率计数器仍每秒采样。
- 与其他向任务栏嵌入内容的软件同时运行时，可能发生显示区域重叠。
