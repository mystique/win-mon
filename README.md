# Win Mon

Win Mon 是一款面向 Windows 11 的轻量级网速监控工具。它在主任务栏通知区域旁显示实时上传和下载速率，也可启用独立的桌面悬浮窗。程序不提供主窗口，日常操作通过右键菜单完成。

当前版本：**1.1.0**（Windows 文件版本：`1.1.0.0`）。本版新增悬浮窗，并优化网络连接分类查询和悬浮窗渲染资源复用。

## 功能

- 在主任务栏上以两行文字显示上传、下载速率，每秒更新一次
- 支持汇总活动硬件网络接口的速率，或监控指定网络接口
- 可启用置顶、可拖动的悬浮窗，显示速率、近期趋势和活动动画
- 自动使用 `K/s`、`M/s`、`G/s` 单位显示速率
- 支持选择显示字体，任务栏文字与悬浮窗共享字体和样式
- 支持设置登录 Windows 后自动启动
- 可选择是否通过右键单击速率文字打开菜单
- 自动适配 DPI、任务栏主题颜色以及 Explorer 重启
- 以普通用户权限运行，不需要管理员权限

## 系统要求

### 运行

- Windows 11 x64
- 使用任务栏速率文字时，需要位于主显示器底部的任务栏

任务栏速率文字仅显示在主显示器的底部任务栏上，不显示在副屏任务栏中。主任务栏不可用或不位于底部时，任务栏速率文字会隐藏；托盘菜单和已启用的悬浮窗仍可使用。悬浮窗可拖动到其他显示器。

### 构建

- Visual Studio 2022，并安装“使用 C++ 的桌面开发”和 MFC 组件
- CMake 3.25 或更高版本
- Windows 11 SDK

## 构建与测试

在已配置 Visual Studio 编译环境的终端中运行：

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

构建完成后，程序位于：

```text
build/Release/WinMon.exe
```

## 使用方法

1. 启动 `WinMon.exe`。
2. 通过通知区域中的 Win Mon 图标打开右键菜单。
3. 在 **Network to Monitor** 中选择 **All** 或指定网络接口。
4. 根据需要启用 **Launch at Login**、**Right-Click Speed Text**、**Show Floating Display**，或通过 **Set Font...** 调整字体。
5. 选择 **Exit** 退出程序。

除网络接口选择外，登录启动、速率文字右键菜单开关、悬浮窗开关及位置和字体设置会保存到当前用户的注册表中。每次启动时，网络接口选择会恢复为 **All**。**All** 汇总处于连接状态的硬件接口；虚拟和隧道接口可单独选择，但不参与汇总。所选接口断开时显示零速率，接口从系统中消失时恢复为 **All**。

### 悬浮窗

通过 **Show Floating Display** 开启，默认关闭。首次开启时位于主显示器工作区右上角；拖动后保存位置，原位置在当前显示器布局中不可用时自动回到主显示器。

- 默认只显示蓝色下载速率，鼠标悬停时显示绿色上传速率；背景曲线展示最近最多 48 次采样的平滑趋势。
- 左侧圆环和脉冲反映相对网络活动，不代表网卡带宽利用率。
- 左键拖动移动位置，右键打开与托盘相同的菜单；不受 **Right-Click Speed Text** 开关影响。
- 不占用任务栏或 Alt-Tab 条目，拖动时不抢占焦点；阴影区域允许鼠标点击穿透。
- **Set Font...** 同时更改两处显示的字体和样式，悬浮窗使用适合紧凑布局的独立字号。
- 动画遵循 Windows 动画设置。关闭系统动画后，悬停布局立即切换，活动光晕保持静态。

## 实现概览

项目使用 C++20、Win32 和 MFC 构建：

- `WinMonCore`：负责网络速率计算、格式化、网络接口选择和菜单模型，不依赖 MFC 或窗口句柄。
- `WinMon`：作为轻量级 Windows 外壳，负责托盘图标、任务栏速率文字、悬浮窗、菜单、定时采样、设置和 Explorer 恢复。
- `RateStrip` 只管理任务栏文字，`FloatingRateDisplay` 独立管理悬浮窗、阴影、拖动和动画；两处共用字体选择与失败恢复逻辑。字体更新中途失败时会尝试恢复两处，恢复失败则按已保存设置继续重试。
- `NetworkObservationReader` 集中读取网卡数据和缓存连接分类，定时采样与菜单共用同一实例；网卡列表变化时立即刷新分类，正常缓存 30 秒，查询失败后 2 秒重试。
- 速率文字以子窗口方式嵌入主任务栏，并依据通知区域的位置进行布局；程序不会缩放或永久修改任务栏中的其他窗口。
- 网络计数器每秒读取一次；经典“网络连接”分类复用缓存，网卡 GUID 集合变化时刷新，正常每 30 秒校准，查询失败后每 2 秒重试。
- `FloatingRateRenderer` 使用 Direct2D 软件渲染、DirectWrite 和分层窗口实现透明显示。活动时约 30 FPS 的动画与每秒采样独立；空闲且无悬停过渡时停止动画定时器，关闭悬浮窗时销毁窗口并释放渲染目标。
- 悬浮窗复用文字布局、圆弧、趋势路径和 DC/DIB 缓冲；字体、读数、采样历史或 DPI 变化时更新相应资源。阴影复用，仅在目标重建或提交到新的阴影窗口时重新上传；合成预览像素按需生成。
- CTest 覆盖核心逻辑、渲染与缓存失效的一致性，以及原生悬浮窗的移动、重建和 GDI 资源释放。

## 已知限制

- 仅支持 Windows 11 x64。
- 仅在主显示器底部任务栏显示速率文字。
- 不支持 Windows 10；任务栏嵌入不支持副屏或垂直/顶部布局，悬浮窗不受这些任务栏布局限制。
- 网卡 GUID 集合不变时，经典“网络连接”分类的变化最多可能延迟约 30 秒反映；速率计数器仍每秒采样。
- 与其他向任务栏嵌入内容的软件同时运行时，可能发生显示区域重叠。
