# 02: 双半环活动指示与下载趋势

Status: ready-for-human
Implementation: complete
Acceptance: pending manual Windows scenarios
Blocked by: None — 01 implementation complete; manual acceptance remains tracked separately

**What to build:** 用户能在实际 Floating Rate Display 中看到上传上半环、下载下半环随各自速率变化，并通过右下下载曲线观察近期活动；切换 Network to Monitor 时不会混入旧网络的图形历史。

## Parent

Compact Floating Rate Display — Direct2D / DirectWrite 实现规格及其中的视觉参考。沿用工单 01 的具体绘图单元与位图测试入口，不建立另一条渲染或测试路径。

## Implementation constraints

- 复用现有速率传入边界和最多 48 个 Rate Sample 的历史存储；图形平滑沿用系数 0.35。首个样本直接成为初始平滑值，之后再平滑。
- 上下半环共用最近最多 48 个双向平滑样本的峰值作标尺，下限 1000 bytes/s；各自值与标尺之比线性映射并限制在 [0,1]。这表示近期相对强度，不是带宽百分比。
- 保留每秒采样节奏，不引入高频绘图计时器、整环旋转或新设置。数值保持当前 Rate Sample 的格式化结果，只有图形平滑。
- 网络选择改变和既有自动回退应在现有选择流程中重置浮动图形历史；不改变核心计算、会话内选择或持久化语义。

## Acceptance criteria

- [x] 青绿 Upload Rate 弧只在上半环，从右端经顶部逆时针向左增长；蓝色 Download Rate 弧只在下半环，从右端经底部顺时针向左增长。
- [x] 屏幕坐标 x 向右、y 向下时，上传扫角为 -180°×比例，下载为 +180°×比例。比例 0.5 的终点分别在顶部和底部，比例 1 的终点均在左侧；两侧分界可有小间隙，不改变语义。
- [x] 两半环能同时显示不同长度，未填充段保留暗轨道，线条抗锯齿且端点为圆头。满值不画整圆，零值不留下圆头亮点。
- [x] 原始当前速率为零时对应亮弧立即清空；负值及非有限绘图输入按零处理且不污染后续历史和标尺。比例变化可缩回，旧峰值离开历史窗口后可重新定标。
- [x] 在实际 Rate Sample 驱动下，圆环及时更新，上传和下载不串色、不交换方向，下载数值与上传读数继续来自当前样本。
- [x] 右下仅显示 Download Rate 趋势，时间从左到右，复用至多 48 个真实样本；不足窗口长度时不虚构过去的数据。
- [x] 曲线标尺使用下载历史峰值、下限 1000 bytes/s；没有样本时没有伪造曲线，全零时显示安静基线，曲线不越出绘图区或产生负值。无需为此新增平滑插值算法。
- [x] 手动更换 Network to Monitor 或发生现有自动回退后，历史及平滑状态重置，新样本不会与旧 NIC 的曲线连接；无网络及网络闲置显示零速率。
- [x] 经工单 01 的最终位图测试入口，使用确定样本序列覆盖仅上传、仅下载、两者不同值、0／0.5／1 比例、标尺峰值过期、零值及异常输入。检查用户可见的弧段位置／颜色，不断言绘图 API 调用顺序。
- [x] 同一入口覆盖空历史、少量历史、满历史及网络切换重置。网络选择流程使用现有可测边界验证，不建立新的应用模拟框架。
- [ ] CMake Release 构建与 CTest 通过；实际窗口验收上传／下载方向、曲线、闲置和切换网络，提供真实大小与放大细节截图，对照已保存原型。

### 2026-09-20 下载优先与双向活动修订（当前设计）

本节覆盖此前“圆内下载读数／右下仅下载曲线／无高频绘图计时器”的布局和动画限制，依据用户新的四项要求：

- 保持 132×48 DIP。下载读数移到右侧，与上传上下排列；上传约 10.9 DIP、低对比青绿，下载约 15.3 DIP、近白。读数仍来自当前样本，长数字独立缩小。
- 上下半环线宽由约 1.64 DIP 加粗为约 2.73 DIP，保留两端约 2 DIP 圆头间隙。
- 圆心光晕向外扩散并消退，活动越强越明显、周期越短（约 2.2～1.0 秒）。最大半径含描边保持小于外环内侧；空闲立即停止。窗口可见且有流量时才启用约 30 FPS 原生计时器；关闭 Windows 客户区动画效果时显示静态活动光晕。采样仍每秒一次，动画不增加历史样本。
- 青绿上传曲线与蓝色下载曲线在右侧全高度重合，使用共同近期峰值标尺、低透明度；文字采用薄深色字形衬边保证可读性。

Release 构建及 3/3 CTest 通过。位图回归检查圆内扩散范围、不同动画相位、闲置静止以及两种曲线使用上半区域；原生窗口测试已运行真实计时器消息。原多显示器及人工验收待办仍保留。
