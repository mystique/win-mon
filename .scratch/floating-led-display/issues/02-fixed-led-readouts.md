# 02: 固定九字符位的 Punctum LED 读数及字体解耦

**What to build:** 用户无需安装字体即可在浮动显示中读出稳定的九字符位 LED 上传／下载速率，每个字符拥有自己的 35 盏灯。Set Font 继续控制任务栏，浮动字形保持固定。

**Blocked by:** 01：双端半环与按原型比例排列的分区图表。

Status: resolved

- [x] 从规格锁定版本的 Punctum 提取上下箭头、0–9、点号、K/M/G、斜杠和小写 s 共 18 个字形，编译时内置；实际窗口绘制读数，不依赖安装字体、联网或全字符串图片。
- [x] 每行固定九个字符位：方向箭头、三个整数位、点号、小数位、三个单位位。每个有形字符位恰好 5×7 灯，前导空位全暗，不点亮前导零；字符之间无灯，不绘制整行底屏。
- [x] 保留上传青绿／下载青蓝与较暗单位；亮暗灯同格，暗灯弱于单位亮灯。字间距收紧但可分辨，各数字长度、单位切换不改变锚点、点距、圆径和字号。
- [x] 使用既有格式化结果，最大文字值 999.9；按规格处理超过容量及舍入得到 1000.0 的边界，不截低位冒充数值，不修改 Rate Strip 或核心格式化。
- [x] 接通目前被渲染器忽略的速率文字；未知字符受控失败并保留成功帧，不越界读取字形资源。
- [x] 移除 Floating Rate Display 对 Rate Font 的读取、设置、恢复和事务依赖，更新所有相关调用与测试；任务栏字体保存／回滚继续生效，浮动故障不阻塞任务栏字体设置。
- [x] 在 01 的真实布局中验证 0.0、1.2、12.8、999.9 及 K/M/G，各字符位和组间距固定，读数不挤占图表、保持 5:8 比例。输出多 DPI 实际尺寸亮暗灯证据。
- [x] Punctum 派生字形资源保留上游版本、来源、版权及 OFL，完整许可随交付物提供；不将字形源数据误归入网站 MIT 许可。
- [x] 更新现行领域说明与 ADR-0008 的共享字体约定；没有新增字体设置或删除已存任务栏字体。
- [x] 沿用离屏、字体事务及真实窗口测试验证 35 灯、九字符位、内容、失败保帧和字体解耦；CMake x64 Release 构建及 Release CTest 通过，记录证据。
