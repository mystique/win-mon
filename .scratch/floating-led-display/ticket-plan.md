## 01：双端半环与按原型比例排列的分区图表

**What to build:** 用户在真实 Floating Rate Display 中看到左右两端相向增长的上传／下载半环，以及对齐半圆、带淡网格和渐变的独立连续曲线。每次采样移动更明显，曲线不越出自己的区域。

**Blocked by:** None (can start immediately).

- [ ] 保留深色胶囊及现有窗口交互，在原生窗口实际呈现新的环与图表；不只交付几何助手。
- [ ] 上半上传青绿、下半下载青蓝；各半环从左右端同时向顶部／底部中点增长，两侧长度相等。验证 p=0、0.25、0.5、1、下降及原始速率归零；满值中点无重叠增粗，水平接缝仍清晰。
- [ ] 圆环外径 D 与上下图表宽度 W 固定为 5:8；外径包含描边，宽度取裁剪矩形，不含组间距。上下图等宽且分别对齐对应半圆，中央间距以规格为准。
- [ ] 实际图表使用低对比网格、连续曲线和向底部渐隐的同色填充；上下网格列对齐，线宽、端帽、网格和填色都严格裁剪，尖峰不能侵入另一图表或未来文字区。
- [ ] 可见历史改为 32 次真实 Rate Sample，每秒一次，满窗每次左移图宽/31；不添加中间采样或空白历史。保留图形平滑系数与共同峰值下限，圆弧及 Activity 同用该窗口，网络切换／回退清空历史。
- [ ] 为后续文字留出稳定区域，在显示态 132×48 DIP 内保留比例；不得为未来文字独立缩窄图表。
- [ ] 沿用离屏和真实窗口测试，验证双端弧、裁剪、真实样本顺序与移动、比例和网络重置；在 96/120/144/192 DPI 输出真实尺寸证据，比例只容许像素取整误差。
- [ ] 同步更新现行领域说明中环方向、图表排列和历史标尺约定；保留历史规格。
- [ ] CMake x64 Release 构建及 Release CTest 通过，记录该票证据，不直接构建 solution。

## 02：固定九字符位的 Punctum LED 读数及字体解耦

**What to build:** 用户无需安装字体即可在浮动显示中读出稳定的九字符位 LED 上传／下载速率，每个字符拥有自己的 35 盏灯。Set Font 继续控制任务栏，浮动字形保持固定。

**Blocked by:** 01：双端半环与按原型比例排列的分区图表。

- [ ] 从规格锁定版本的 Punctum 提取上下箭头、0–9、点号、K/M/G、斜杠和小写 s 共 18 个字形，编译时内置；实际窗口绘制读数，不依赖安装字体、联网或全字符串图片。
- [ ] 每行固定九个字符位：方向箭头、三个整数位、点号、小数位、三个单位位。每个有形字符位恰好 5×7 灯，前导空位全暗，不点亮前导零；字符之间无灯，不绘制整行底屏。
- [ ] 保留上传青绿／下载青蓝与较暗单位；亮暗灯同格，暗灯弱于单位亮灯。字间距收紧但可分辨，各数字长度、单位切换不改变锚点、点距、圆径和字号。
- [ ] 使用既有格式化结果，最大文字值 999.9；按规格处理超过容量及舍入得到 1000.0 的边界，不截低位冒充数值，不修改 Rate Strip 或核心格式化。
- [ ] 接通目前被渲染器忽略的速率文字；未知字符受控失败并保留成功帧，不越界读取字形资源。
- [ ] 移除 Floating Rate Display 对 Rate Font 的读取、设置、恢复和事务依赖，更新所有相关调用与测试；任务栏字体保存／回滚继续生效，浮动故障不阻塞任务栏字体设置。
- [ ] 在 01 的真实布局中验证 0.0、1.2、12.8、999.9 及 K/M/G，各字符位和组间距固定，读数不挤占图表、保持 5:8 比例。输出多 DPI 实际尺寸亮暗灯证据。
- [ ] Punctum 派生字形资源保留上游版本、来源、版权及 OFL，完整许可随交付物提供；不将字形源数据误归入网站 MIT 许可。
- [ ] 更新现行领域说明与 ADR-0008 的共享字体约定；没有新增字体设置或删除已存任务栏字体。
- [ ] 沿用离屏、字体事务及真实窗口测试验证 35 灯、九字符位、内容、失败保帧和字体解耦；CMake x64 Release 构建及 Release CTest 通过，记录证据。

## 03：随活动变化的动态水波及计时器生命周期

**What to build:** 用户看到环内持续传播的水波，速度和水位响应网络活动，高负载仍保有可见水线；空闲、窗口隐藏和系统动画偏好下行为正确。

**Blocked by:** 01：双端半环与按原型比例排列的分区图表。

- [ ] 真实窗口使用现有约 30 FPS 原生计时器推进横向传播波形；按真实经过时间保持相位连续，采样到达不从头重播。
- [ ] 采用规格默认活动映射：周期 2200−1200×L 毫秒，活动水位目标 15%+65%×L，零活动目标零，约 450ms 平滑回落；高活动仍可见动态水面，波峰及填色裁剪在环内。
- [ ] 动画只更新视觉，不添加 Rate Sample、不移动图表历史、不修改读数；不同相位下图表和任何已有文字输出保持不变。
- [ ] 活跃窗口显示时运行，零活动回落完成后停止，整个窗口隐藏时停止，重新显示时正确恢复；网络切换清空旧活动和水位。
- [ ] Windows 禁用客户端动画时使用静态目标水位，不推进相位；计时器或渲染失败沿用现有受控处理。
- [ ] 本票不抢先实现文字开关；后续 04 在同一个计时器生命周期中加入宽度过渡运行条件，不新增平行动画计时器。
- [ ] 用现有离屏相位输入及真实窗口消息验证传播运动、高活动、升降速、闲置／隐藏恢复、关闭动画和资源释放；输出真实大小动画证据，不只提交放大演示。
- [ ] 更新现行领域说明中的活动动画行为；CMake x64 Release 构建及 Release CTest 通过，记录证据。

## 04：持久化菜单文字开关与平滑收窄／展开

**What to build:** 用户在 Operator Menu 切换 Show Floating Speed Text，浮动显示同步淡出文字并收窄，或展开并淡入；偏好跨重启保存，快速切换、拖动和 DPI 变化保持顺畅。

**Blocked by:** 02：固定九字符位的 Punctum LED 读数及字体解耦；03：随活动变化的动态水波及计时器生命周期。

- [ ] 在 Show Floating Display 后接通勾选项 Show Floating Speed Text，默认开启；所有既有菜单入口一致。核心菜单状态／动作、宿主、实时应用和设置保存构成完整路径。
- [ ] 保存 FloatingRateTextVisible 用户 DWORD，0/1 对应隐藏／显示；缺失、错误类型、不可读或未知值默认显示。实时应用失败不保存，保存失败按既有事务恢复偏好、勾选及可见效果。
- [ ] 隐藏两行箭头、文字、单位和暗灯时胶囊收窄，显示时展开；圆环与上下图表保持局部位置、尺寸、5:8 比例及历史，不缩放整图，不保留原文字空白区。
- [ ] 收起默认 220ms、展开 180ms，使用规格 ease-out cubic，同步淡化亮暗灯；快速反向从当前宽度／透明度继续，按剩余距离缩放时间，不跳端点、不排队旧过渡。
- [ ] 与水波共用计时器；网络空闲仍完成宽度过渡，无活动和过渡后停止；仅隐藏文字不停止活跃水波。系统禁用动画时直接到端态。
- [ ] 每帧主体和阴影真实尺寸、像素缓冲、阴影轮廓及命中区域同步，缩窄后原文字区点击穿透。保留不激活、拖动和右键，不留下透明可点击尾部。
- [ ] 默认左上锚点稳定，显示器边缘展开时按规格平滑约束目标位置；过渡中拖动、DPI／显示器变化重算几何，不越界、不裁图。持久化有效位置而非动画进度。
- [ ] 浮动窗口关闭时可配置，打开时直接以最新目标尺寸显示；重启、恢复及关闭过程中切换不丢失偏好，关闭整个窗口取消过渡。
- [ ] 复用菜单、设置事务、离屏和真实窗口测试验证勾选、默认值、回滚、完整文字消失、端态／中间帧、反向、计时器、点击穿透、边缘、DPI 和恢复。输出多 DPI 收起／展开真实大小证据。
- [ ] 更新现行领域说明及 ADR-0007 的新增偏好；对四票组合完成一次最终深浅背景、多 DPI、短／满读数、动画与恢复验收，保留许可交付证据。
- [ ] CMake x64 Release 配置、构建及 Release CTest 通过，记录最终结果和未覆盖项，不直接构建 solution。
