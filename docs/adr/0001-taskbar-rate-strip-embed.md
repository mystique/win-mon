# Taskbar Rate Strip via Win11 shell embed

The Rate Strip shows two-line rates in either the notification-side or left-side taskbar locus selected by Speed Text Position (default Right). We embed a child window into the primary `Shell_TrayWnd` (TrafficMonitor Win11 path: parent to the tray shell window, anchor near the notification area), rather than a topmost overlay or undocumented taskbar pin APIs. The strip uses fixed numeric, unit and arrow columns and re-reads the notification-area geometry during each one-second Rate Sample so a changing tray width cannot overlap the strip. The independent Floating Rate Display is governed by ADR-0008.

Overlay positioning breaks more easily under fullscreen, overview, and shell restarts; pin APIs are out of scope. Classic taskbar surgery (shrinking `MSTaskSwWClass`) is explicitly rejected — Win11-only, no permanent layout damage to the task list. If the primary taskbar is not bottom-aligned, hide the Rate Strip and keep the Tray Icon. The Tray Icon variant and Rate Strip text color use the same `AppsUseLightTheme` registry state, with dark mode as the fallback when that state is unavailable.

Shell recovery uses a hidden top-level message sink because the registered `TaskbarCreated` notification is a system broadcast and is not delivered to message-only windows.

Extension (2026-10-11; [spec](../../.scratch/taskbar-rate-position/spec.md)): Speed Text Position allows the primary bottom taskbar's left-side location in addition to the existing notification-side location. This extends the original notification-side-only scope while retaining shell embedding and the prohibition on task-list surgery; if the left-side region cannot be verified free of shell controls, hide the strip temporarily and retry rather than cover those controls or silently change the saved location.

Extension (2026-10-14): replace the Rate Strip's GDI font text with shared Direct2D Punctum LED readouts, preserving the existing layered child, placement, click-through and menu hit testing. Capacity is now 999.9 in the selected unit, matching the floating display. Use DPI-scaled fixed geometry and theme-specific lamp colors. The fixed embedded glyphs supersede the Rate Font appearance contract; the font chooser is removed from the Operator Menu while existing registry values are retained.
