# Win11 primary bottom taskbar only

Win Mon supports only Windows 11, the primary monitor’s taskbar, and bottom alignment for the Rate Strip. It does not implement classical Win10 ReBar embedding, secondary taskbars, or vertical/left/top strip layouts.

Keeps the shell integration surface small and matched to the product screenshot. The Rate Strip remains hidden until a bottom primary taskbar exists; the Tray Icon and Operator Menu remain available. With the addition of ADR-0008, the optional Floating Rate Display also remains available independently of taskbar placement and may be moved between monitors.
