# Win11 primary bottom taskbar only

v1 supports only Windows 11, the primary monitor’s taskbar, and bottom alignment for the Rate Strip. No classical Win10 ReBar embedding, no secondary taskbars, no vertical/left/top strip layout.

Keeps the shell integration surface small and matched to the product screenshot. Multi-monitor and non-bottom taskbars remain tray-only (Operator Menu still works); Rate Strip is hidden until a bottom primary taskbar exists.
