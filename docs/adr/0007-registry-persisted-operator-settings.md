# Operator settings persist under HKCU\Software\Win Mon

Launch at Login, Right-Click Speed Text, Show Floating Display, the Floating Rate Display position, and Rate Font survive a restart. The product key is `HKEY_CURRENT_USER\Software\Win Mon`; the two display toggles are DWORD values (`RightClickSpeedText` and `FloatingRateDisplay`, 0 or 1, absent means off), and the floating display stores its absolute desktop position as `FloatingRateDisplayPosition`. Rate Font is stored atomically as a versioned `REG_BINARY` value named `RateFont`, containing the selected `LOGFONTW` and point size; invalid or unreadable data falls back to the current Windows UI message font. Launch at Login uses its own `HKCU\...\CurrentVersion\Run` entry. Network to Monitor remains session-only as defined by ADR-0004.

A setting the user must re-set at each logon is worse than no setting, and these settings are user-scoped registry state, so no install surface or elevation is added. HKCU keeps the write path available to a normal user (ADR-0005) and a read failure degrades to the documented default rather than blocking startup. The registry rather than an INI file avoids picking a config location and keeps the process free of file I/O on the startup path. Revisit if settings grow beyond a handful of flags, where a single serialized blob would read better than one value per flag.
