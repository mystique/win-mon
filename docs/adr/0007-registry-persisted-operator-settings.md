# Operator settings persist under HKCU\Software\Win Mon

Supersedes the persistence half of ADR-0004. Operator toggles — Launch at Login and Right-Click Speed Text — survive a restart. The product key is `HKEY_CURRENT_USER\Software\Win Mon`; the right-click toggle is the DWORD `RateStripContextMenu` (0 or 1, absent means off). That value name predates the menu relabel and is deliberately left alone, since renaming it would silently discard a saved choice. Launch at Login keeps its own `HKCU\...\CurrentVersion\Run` entry (ADR-0004 revisited). The Network to Monitor choice is still not persisted: it resets to All NICs every launch.

A toggle the user must re-set at each logon is worse than no toggle, and both settings are already user-scoped registry state, so no install surface or elevation is added. HKCU keeps the write path available to a normal user (ADR-0005) and a read failure degrades to the documented default rather than blocking startup. The registry rather than an INI file avoids picking a config location and keeps the process free of file I/O on the startup path. Revisit if settings grow beyond a handful of flags, where a single serialized blob would read better than one value per flag.
