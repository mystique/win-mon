# Floating Rate Display alongside the taskbar Rate Strip

Win Mon offers an optional Floating Rate Display alongside its embedded Rate Strip. It is a draggable, always-on-top, taskbar-free desktop surface because the taskbar strip is intentionally unavailable when the primary taskbar cannot host it; its persisted absolute position returns to the primary work area's upper-right corner only when no usable portion remains on any current display.

The display uses Direct2D software rendering into a per-pixel-alpha layered window. A separate mouse-transparent shadow window lets shadow clicks reach other processes without making the body noninteractive. It shares Monitored Network with the Rate Strip and offers the same Operator Menu on right-click. Both displays use embedded Punctum LED glyphs under SIL OFL 1.1. Show Floating Display and desktop position persist under ADR-0007.

Rate Samples remain once per second. A separate approximately 30 FPS timer animates traveling water and reversible text-width transitions, stopping when idle with no transition or when hidden, and respecting Windows' animation preference. Reusable glyph data, sample geometry, shadow pixels and presentation buffers keep animation frames from rebuilding unchanged resources; combined preview pixels are generated only when requested.

Extension (2026-10-11; [spec](../../.scratch/floating-led-display/spec.md)): semicircles fill from both endpoints, trends use independent clipped regions and a 32-sample scale, and chart width is exactly 1.6 times outer ring diameter at every DPI and visibility state. Each readout has nine fixed cells, capacity 999.9: the decimal uses 21 lamps (3x7), other cells use 35 (5x7). Show Floating Text resizes both actual layered windows while fading all lamps, using the existing native animation timer and Windows animation preference. It replaces the previous shared-font and hover-readout conventions.

Extension (2026-10-11): chart visibility is independent of text visibility; hiding both leaves a circular body. Native double-clicks within that body cycle charts on, text on, text off, charts off. Existing content at startup or after a menu visibility change is hidden first (text before charts). The display keeps only the cycle direction; the host applies each step through the existing Operator Menu setting transaction so persistence and rollback remain shared. Failure does not advance the cycle. Circular hit testing is DPI-aware, while dragging and right-click menu access remain available.
